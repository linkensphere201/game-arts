# Glossary

- Reference conditioning: using an image to guide appearance; not guaranteed pixel preservation.
- Inpainting/outpainting: regenerate a masked region / extend the canvas.
- Semantic editing: prompt-directed changes interpreted by an image model.
- Editable text layer: retains literal text and font/layout properties.
- Raster text layer: an image containing letter pixels, even if its background is transparent.
- RGBA decomposition: splitting a flattened image into image layers; not recovery of original font objects.
- Compositing: combine independent visual and text layers in defined order.
- VRAM / Windows commit / disk: separate resource constraints; success in one does not imply success in the others.
- poster-cover/M1: this side task's M1, not the parent game-arts project's M1.
