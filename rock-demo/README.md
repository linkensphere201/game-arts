# Independent stone demo

Open project.godot in Godot 4.7.2 and F5. 1 = realistic closeup, 2 = cartoon closeup, 3 = comparison; RMB orbit, mouse wheel zoom. See stone_asset/README.md for portable asset usage and limits. Local executable: ../builds/stone-study.exe.

Rebuild: run Blender with `--background --factory-startup --python scene-demo/authoring/build_rock_study.py` from the repository root; Godot `--headless --path rock-demo --editor --import --quit`; then Godot `--path rock-demo --script res://build_demo.gd`. Named generated outputs are overwritten: preserve manual edits first. The demo reference GLB is copied from the retained original stone; it is not generated by the new stone recipe. Code-only clones require generating assets and supplying that optional comparison fixture before rebuilding the four-way demo.

The standalone asset needs only stone_asset/, not the demo reference, camera, lights or scene. Packaging and validation: tools/package-stone.py and validation/stone/README.md. Candidate archives are local outputs; no remote publication performed.
